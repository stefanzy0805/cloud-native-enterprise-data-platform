# Junior DE Learning Notebooks

这套笔记对应 `Junior_DE_Checklist.html`，用于补 Junior Data Engineer 的基础知识缺口。建议顺序学习：

| 顺序 | Notebook | 主题 |
|---|---|---|
| 00 | `00_Roadmap/01_学习路线与最小闭环.ipynb` | DE 学习路线与最小能力闭环 |
| 01 | `01_SQL/01_SQL查询基础.ipynb` | SQL 查询、NULL、CASE WHEN |
| 01 | `01_SQL/02_聚合Join与窗口函数.ipynb` | GROUP BY、Join、ROW_NUMBER |
| 02 | `02_Python/01_基础语法文件异常.ipynb` | Python 基础、文件、异常 |
| 02 | `02_Python/02_工程化脚本入门.ipynb` | main、logging、脚本结构 |
| 03 | `03_Pandas/01_DataFrame清洗聚合.ipynb` | Pandas 清洗、聚合、Join |
| 04 | `04_Data_Warehouse/01_数仓建模基础.ipynb` | 事实表、维度表、粒度、分层 |
| 05 | `05_Pipeline_Scheduling/01_ETL_ELT与Airflow入门.ipynb` | ETL/ELT、Airflow DAG 基础 |
| 06 | `06_Cloud_Tools/01_GCP_Linux_Git_Docker入门.ipynb` | GCP、Shell、Git、Docker |
| 07 | `07_Storage_Quality/01_文件格式与数据质量.ipynb` | CSV/JSON/Parquet、质量检查 |
| 08 | `08_Spark/01_PySpark入门.ipynb` | Spark 概念、PySpark 常用操作 |
| 09 | `09_Portfolio/01_项目与面试表达.ipynb` | 项目包装、简历、STAR 面试 |

学习建议：

1. 先完成 `00` 到 `03`，建立 SQL + Python + Pandas 最小闭环。
2. 再学 `04` 到 `07`，补数仓、调度、云工具、数据质量。
3. 最后学 `08` 和 `09`，把 Spark 入门和项目表达补上。
4. 每学完一个 notebook，就回到 HTML checklist 勾选对应知识点。
